# TaskManager

nKits 的 TI-Nspire 原生任务管理器。面向 CX / CX II 的 CAS 与非 CAS 型号，需要 Ndless r2023；CX 使用 OS 4.5.5.79，CX II 使用 OS 6.4.0.74。界面随系统语言自动选择中文、法文或英文，其他语言使用英文。各型号验证情况见[项目说明](../README.md)。

## 功能

- 查看 Nucleus 任务及名称、状态、调度次数、优先级、抢占、时间片和栈信息；终止选中的任务。
- 查看内存池的地址、容量、最小分配量、可用空间及等待任务；删除内存池。
- 查看事件组的标志及等待任务；删除事件组。
- 查看队列的地址、容量、可用空间、消息数量与类型、消息长度及等待任务；删除队列。
- 手动刷新列表与详情，刷新后按对象身份保留选中项。
- 设置中可暂时关闭中断，按 Enter 恢复，Esc 恢复并返回；关于页显示版本信息。

**终止或删除系统对象可能使计算器死机、丢失数据。** 操作前会再次确认，当前应用任务受保护。只操作自己创建、用途明确的对象，不要凭名称猜测。

## 使用

传入并打开 `taskmanager.tns`，在类别菜单中用 ↑/↓ 选择任务、内存池、事件组、队列、设置或关于，按 Enter 直接打开；返回时保留所选类别，Esc 退出。列表使用系统字体，名称与地址共同标识对象，`*` 表示当前任务。详情分页显示全部字段，状态提供翻译和原始 RTOS 名称。设置与确认使用原生表单；终止或删除须先勾选操作再保存，取消不会执行。退出时恢复系统画面。

菜单、对象列表和详情共用 nTexts 风格的配色、标题与底部提示。列表以整行高亮标明选中对象，包含名称、地址和第二行状态；详情仍分页显示全部字段，设置和操作确认保留系统原生表单。

| 按键 | 操作 |
|---|---|
| ↑ / ↓ | 类别或列表选择；详情翻页 |
| ← / → | 列表或详情翻页 |
| Enter / 触摸板点击 | 打开类别或列表详情；原生表单使用系统导航 |
| 1 / R | 刷新列表 |
| R | 刷新详情 |
| 1 | 详情页终止任务或删除对象 |
| Esc | 取消、返回；类别菜单退出 |

中断设置默认不关闭中断；勾选并保存后才临时关闭。关闭期间定时器和 USB 暂停，只显示预先绘制的画面，只接受实体 Enter 或 Esc 恢复，不调用原生表单或系统绘字。中断设置、刷新及管理操作会保留原有 IRQ/FIQ 掩码。程序退出后返回系统。

## 构建

在 Ndless SDK 环境进入本目录：

```sh
make
make host-test
make native-test
```

输出为 `taskmanager.tns`。中断回归程序为 `build/test_interrupts.tns`，在计算器或模拟器中运行。
