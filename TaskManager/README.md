# TaskManager

nKits 的 TI-Nspire 原生任务管理器。面向 CX / CX II 的 CAS 与非 CAS 型号，需要 Ndless r2022；CX 使用 OS 4.5.5.79，CX II 使用 OS 6.4.0.74。各型号验证情况见[项目说明](../README.md)。

## 功能

- 查看 Nucleus 任务及名称、状态、调度次数、优先级、抢占、时间片和栈信息；终止选中的任务。
- 查看内存池的地址、容量、最小分配量、可用空间及等待任务；删除内存池。
- 查看事件组的标志及等待任务；删除事件组。
- 查看队列的地址、容量、可用空间、消息数量与类型、消息长度及等待任务；删除队列。
- 手动刷新列表与详情，刷新后按对象身份保留选中项。
- 设置中可暂时关闭中断，按 Enter 恢复，Esc 恢复并返回；关于页显示版本信息。

**终止或删除系统对象可能使计算器死机、丢失数据。** 操作前会再次确认，当前应用任务受保护。只操作自己创建、用途明确的对象，不要凭名称猜测。

## 使用

传入并打开 `taskmanager.tns`，选择管理类别。列表中的 `*` 表示当前任务。退出时恢复系统画面。

| 按键 | 操作 |
|---|---|
| ↑ / ↓ | 选择 |
| ← / → | 列表翻页 |
| Enter / 触摸板点击 | 打开、确认 |
| 1 / R | 刷新列表 |
| R | 刷新详情 |
| 1 | 详情页终止任务或删除对象 |
| Esc | 取消、返回；首页退出 |

关闭中断期间定时器和 USB 暂停，只接受实体 Enter 或 Esc 恢复。中断设置、刷新及管理操作会保留原有中断状态。程序退出后返回系统。

## 构建

在 Ndless SDK 环境进入本目录：

```sh
make
make host-test
make native-test
```

输出为 `taskmanager.tns`。中断回归程序为 `build/test_interrupts.tns`，在计算器或模拟器中运行。
