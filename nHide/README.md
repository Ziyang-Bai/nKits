# nHide

nKits 的 TI-Nspire 原生文件隐藏工具。通过秘密按键访问文件系统根目录，使用系统的剪切、粘贴和新建文件夹功能隐藏、恢复文档。面向 CX / CX II 的 CAS 与非 CAS 型号，需要 Ndless r2022。各型号验证情况见[项目说明](../README.md)。

## 使用

1. 传入并运行 `nhide.tns`。窗口显示当前是否启用根目录访问，可选择启用、停用或查看帮助。
2. 回到主页，按住 `=` 再打开「我的文档」（`2`）。CX 模拟器若仍停在主菜单，保持 `=` 约 2 秒，再松开并按 Enter；其余情况下进入列表后松开按键。
3. 在根目录新建自己的文件夹，将 `/documents` 中需要隐藏的文件或文件夹剪切、粘贴到其中。再次打开普通「我的文档」时，它们不再显示。
4. 恢复时，用相同按键进入根目录，将文件剪切、粘贴回 `/documents` 中原来的位置。文件名与内容不经 nHide 转换；重启也不会自动移回文件。

不按 `=` 打开「我的文档」仍浏览 `/documents`。停用只关闭本次开机的秘密入口，不删除或恢复文件；重新启用即可访问。与 nProtect 同时使用时，仍须满足 nProtect 的访问条件。

展开根目录中的 `documents` 文件夹后，可以继续打开其中的程序、修改设置及返回原文件列表。

**请勿删除、重命名或移动系统文件夹，即使它们看似为空。** 隐藏不是加密；其他有根目录访问能力的软件仍能读取文件。粘贴遇到同名目标时，取消替换或改用没有重名文件的目录，不要覆盖需要保留的数据。

如需开机自动加载，将程序放在 `/documents/ndless/startup/nhide.tns`；开机加载不弹窗口。不再使用前请先恢复隐藏文件，再将程序移出启动目录。

当前原生入口支持 CX OS 4.5.5.79、CX II OS 6.4.0.74（均含 CAS 与非 CAS）。不支持的系统或不匹配的入口会拒绝安装，不写入未知地址。

## 构建

在 Ndless SDK 环境进入本目录运行 `make`，输出为 `nhide.tns`。
