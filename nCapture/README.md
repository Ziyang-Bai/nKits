# nCapture

TI-Nspire CX/CX II + Ndless 驻留截图工具。支持快捷键截图、预览、系统另存为和重复保存。

适配 CX / CX CAS 的 OS 4.5.5.79 和 CX II / CX II CAS 的 OS 6.4.0.74，需要 Ndless r2023。界面随计算器系统语言自动使用中文、法语或英语。CX / CX CAS 已在 Firebird 中验证；CX II 系列待完整验证。截图用于系统页面。

## 安装与启动

运行 `ncapture.tns`，退出菜单后按 `Ctrl+.` 截图。可与 nClock 同时使用。

将程序放入 `/documents/ndless/startup/`，开机重新启用 Ndless 后自动加载。更新程序、系统或 Ndless 前先重启，启动目录保留一个版本。

再次运行程序打开菜单：用方向键选择快捷键、默认输出、保存详情或关于，按 `Enter` 打开，按 `Esc` 或选择返回退出。快捷键页面的复选框仅在保存后应用，取消不改开关；保存详情显示次数、最后路径及错误。

菜单与预览采用 nTexts 风格的配色、标题和底部提示。驻留预览继续通过原生 GC 函数绘制，不从系统回调进入 Ndless 绘图接口；截图缓冲区、CX II 显示处理及系统另存为保持不变。

## 截图与保存

`Ctrl+.` 截取完整 320×240 系统屏幕并打开预览。`Enter` 或保存按钮打开系统另存为对话框，选择已有目录和文件名后保存。

CX II 从系统的 320×240 逻辑绘图缓冲区截图，避免将图形程序进入／退出时 LCD 短暂错位的过渡画面保存到预览和 BMP。程序进入／退出时的屏幕切换仍由 Ndless 和图形库处理。

保存或取消另存后都回到当前截图的预览，可再次按 `Enter` 保存到其他名称或文件夹。按 `Esc` 或关闭按钮关闭预览，回到系统；下次快捷键截取新画面。

已有同名文件时显示取消 / 替换确认，默认取消。用 `Tab` 选择替换后按 `Enter` 覆盖；按 `Esc` 或直接确认默认选项会保留原文件。

预览打开期间再次按快捷键会保留当前截图。保存成功后增加保存次数，取消另存保留当前截图和次数。

## 快捷键

| 按键 | 操作 |
|---|---|
| Ctrl + . | 截取系统屏幕并打开预览 |
| Enter | 打开另存为；保存后可再次另存 |
| Esc | 取消另存；预览中关闭并返回系统 |
| Tab | 切换系统对话框中的选项 |

## 输出设置

默认路径为 `/documents/capture.bmp.tns`。保存为 24 位 BMP，传到电脑后去掉末尾的 `.tns` 即可打开。

默认输出通过系统 Unicode 输入框依次设置文件夹和文件名。文件夹为 `/documents` 下的已有目录，默认 `/`；文件名包含 `.bmp`，例如 `capture.bmp` 或 `My capture.bmp`。支持中文和法语重音等 Unicode 名称；取消任一步或路径无效时，两项默认值都不变。也可在另存为对话框中修改目录和名称。

另存为会记住最近的目录和文件名。输出设置、快捷键开关和保存次数保留到本次重启。
